# Сообщество ТЕОРА — лендинг «Уровни участия»

Одностраничный сайт о пяти уровнях участия в Сообществе ТЕОРА.
Без внешних зависимостей: статические файлы отдаёт минимальный Node-сервер.

## Структура

```
├── server.js            # статический сервер (слушает process.env.PORT)
├── package.json         # start: node server.js
└── public/
    ├── index.html       # главная страница
    ├── styles.css       # тёмная тема, спектр тёплый→фиолетовый
    ├── app.js           # ⚙ КОНФИГ УРОВНЕЙ + вся логика
    ├── impressum.html   # шаблон (заполнить)
    ├── datenschutz.html # шаблон (заполнить)
    ├── favicon.svg
    ├── og-image.svg
    └── robots.txt
```

## Как менять цены и описания

Всё содержимое уровней — в начале файла **`public/app.js`**, массив `LEVELS`.
Меняете `price`, `phrase`, `idea`, `desc`, `features` — карта, карточки,
таблица сравнения и блок стоимости обновятся автоматически.

- Ссылки на оплату/форму — поле `link` у каждого уровня (сейчас якорь `#join`).
  Подставьте туда ссылку Stripe/формы регистрации.
- FAQ — массив `FAQ`. «Где я сейчас» — массив `CHOOSE`.
  Строки таблицы сравнения — массив `COMPARE_ROWS`.
- Пятый уровень (**Сотворчество**) намеренно без цены и не как тариф —
  живёт отдельным блоком с кнопкой «Подать заявку».

## Локальный запуск

```bash
npm start          # → http://localhost:3000
```

Node ≥ 18. Установка зависимостей не требуется.

## Деплой на Railway

1. Залейте репозиторий в GitHub.
2. Railway → **New Project → Deploy from GitHub repo** → выберите репозиторий.
3. Railway сам определит Node, выполнит `npm install` и `npm start`.
   Порт берётся из `process.env.PORT` автоматически — настраивать ничего не нужно.
4. После деплоя откройте выданный домен (Settings → Networking → Generate Domain).

> Если Railway попросит явную команду запуска — укажите `npm start`.

## Аналитика

Клики по CTA и уровням пишутся в `window.dataLayer` через функцию `track()`
в `app.js`. Чтобы подключить GA4 / Plausible / Matomo — добавьте их вызов
внутри `track()`. Для отладки в консоли: `window.DEBUG_ANALYTICS = true`.
